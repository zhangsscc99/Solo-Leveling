# Solo Leveling 前端视觉设计计划

> 流程遵循 frontend-design skill：先出计划 → 对照题材自查修订 → 再写代码。

## 题材锚点

《我独自升级》的视觉资产不是「奇幻冒险 UI」，而是三件具体的东西：

1. **系统蓝窗**：冷不丁浮现在视野里的半透明全息面板——细边、冷光、切角，是原作辨识度最高的符号；
2. **猎人协会**：军事化评级机构，终端、编号、E→S 字母阶序、配发装备的哑光质感；
3. **传送门 / 影子**：幽紫光，只出现在 Boss、影子、Gate 相关的少数时刻。

因此界面气质 = **配发的战术终端（哑光、方正、安静）+ 系统播报（全场唯一被允许发光的东西）**。不是通用暗色 SaaS 后台。

## Color

| 名称 | hex | 用途 |
|---|---|---|
| `abyss` | `#060B14` | 基底底色——带蓝的黑，不是纯黑 |
| `hull` | `#0C1524` | 终端硬件表面：状态栏、侧栏、按钮底 |
| `text` | `#D7E3F4` | 正文冷白 |
| `system` | `#4FC8FF` | 系统青——只给全息窗、焦点环、激活态，别处不花 |
| `blood` | `#FF4D68` | HP / 警报窗（原作的红窗警告） |
| `gate` | `#9A7BFF` | 传送门紫——Boss / 影子 / 未解锁节点，极少量 |

规避 skill 点名的模板配色：不用奶油+陶土；也不是「纯黑 + 单一荧光色」——底色本身是海军蓝黑，且有三个功能色分工。

## Type

| 角色 | 字体 | 用途 |
|---|---|---|
| display | Rajdhani 600/700（中文回退 Noto Sans SC 700） | 猎人等级字母、数值大号、窗口标题——方正的军事科技感 |
| body | Noto Sans SC 400/500 | 界面文案、按钮、标签 |
| narrator | Noto Serif SC 400 | 旁白段落——中文小说的纸感，首行缩进 2em，行长 ≤68ch |
| data | IBM Plex Mono 400/500 | **只承载数值**（HP 320/400、属性值、金币、快捷键位），不用于标签 |

字号阶梯：11 / 13 / 14 / 16 / 20 / 26（rank 字母）。行高：旁白 1.9，正文 1.6。

## Layout

桌面：三行网格，区间以 1px 发丝线分隔（hairline = 结构信息）。全部左对齐；旁白栏限宽 68ch。

```
┌────────────────────────────────────────────────────────────────────┐
│ [E] 成振宇  Lv.1          HP ▓▓▓▓░░ 320/400   力10 敏12 体8 智10 感14 │
│     第1章 · 双重地下城    MP ▓▓░░░░ 90/150    金币 0        XP 0      │
├──────────────────────────────────────────────────┬─────────────────┤
│ STAGE（滚动文本流）                                │ 档案            │
│                                                  │ [背包|技能|属性|  │
│   旁白段落（衬线、缩进、灰蓝）                      │  地图|任务]      │
│                                                  │ ──────────────── │
│   ╭─ 切角全息窗：系统播报（唯一发光体）─╮           │  当前面板内容      │

│                              ▸ 玩家指令（右对齐等宽回显）│              │
```

移动端：纵向三段，操作区固定底部；侧栏变右滑抽屉（状态栏右侧「档案」按钮开启，Esc/遮罩关闭）；触控目标 ≥44px。

## Principles

1. **全息唯一发光体**：系统窗是唯一的豪赌——切角、细边、内发光、扫描线、一次性「浮现」动效。其余界面全部哑光，零投影。
2. **硬件方正、全息切角**：两种形状语言各司其职——按钮/输入框/面板 2px 方角（配发硬件），系统播报走 clip-path 斜切角（全息投影）。没有「所有卡片同圆角」。
3. **三种声音三种排印**：旁白=衬线缩进段落；玩家=右对齐等宽指令回显；系统=全息窗（标题从正文【】中提取成窗口铭牌，警报类自动转红窗）。不靠彩色标签堆砌。
4. **数值像仪表**：HP/MP 是分格计量条；属性/金币是等宽数字对。数字是界面里最硬的装饰。
5. **动效只回应操作**：只有新系统窗的 ~200ms 浮现、按钮按下、抽屉滑出；无入场动画、无悬停漂浮。`prefers-reduced-motion` 下全静止。

## 自查与修订（写代码前）

对照 skill 的「AI 模板味」清单逐条过：

- **「深色底 + 亮色强调」结构上接近点名的 near-black + single accent**。修订：底色定为明确的海军蓝黑 `#060B14`（不是 #0B0B0B 式伪黑）；强调色扩为青/红/紫三个功能色，且青色只出现在「系统」语境——它是题材文物（系统蓝窗），不是装饰 accent。
- **初稿想用等宽字体做小标签** → 这正是 skill 点名的 mono-label 套路。改为：mono 只承载数值与玩家指令回显，所有标签用 Noto Sans SC。
- **面板标题本想用 tracked-out 小字 eyebrow** → 改为「1px 发丝线 + 文字」的终端分栏题，不追踪字距、无全大写；全息窗内的【系统】铭牌保留字距，因为它是那块被允许夸张的发光体。
- **本想统一 6-8px 圆角面板** → 改为 2px 方角硬件 + 切角全息两种语义化形状，砍掉柔光阴影（只有系统窗有青色 drop-shadow，且那是「发光」不是「投影」）。
- **状态栏差点写成 `姓名 · Lv.1 · E级 · 第1章` 的 middot 串** → 改为分区布局：身份块 / 计量块 / 属性块，用留白和发丝线分隔。副标题内残留的单个 `·` 也在实现后换成了 1px 竖分隔线。

## 自评（实现后）

- **最得意**：系统窗的「铭牌提取」——把服务端文本的【系统】【状态】【警报】前缀抽出来当窗口标题，正文即窗体内容，警报类自动转红窗。一个正则让占位 API 的回复立刻有了原作里「弹窗」的仪式感，且不需要后端配合。
- **最克制**：除全息窗外全场哑光——无卡片、无投影、无圆角、无悬停位移，分区只靠 1px 发丝线（grid gap 透出底色实现）；动效只有系统窗 220ms 浮现和处理中呼吸点，`prefers-reduced-motion` 下全静止。
- **还想再改**：侧栏五面板目前只有背包/属性/地图有真实结构，技能/任务是空态文案——等引擎给出 skills/quests 数据后应做成和状态栏一致的「仪表化」列表（冷却条、倒计时），而不是普通列表。
